CYNTHIA J COPPER - DIGITAL RESUME

Files:
- index.html: main webpage (GitHub Pages entry file)
- style.css: responsive styling
- javascript.js: mobile navigation and interactions
- cynthia-profile.jpeg: place Cynthia's original photo here

IMPORTANT PHOTO SETUP:
Save the original portrait photo in this same folder with the exact name:
cynthia-profile.jpeg
The HTML image path is relative to index.html. If the image has another filename, either rename it to cynthia-profile.jpeg or update the src value in index.html.

GITHUB PAGES:
1. Upload all files directly to the root of your GitHub repository.
2. Ensure index.html is in the repository root (not inside a nested folder).
3. Open Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then save.
5. Check Actions for a successful Pages deployment.

The contact form opens the visitor's default email app; it does not send messages from a server automatically.
